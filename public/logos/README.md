# Logos do carrossel

Coloque aqui os logos das empresas, preferencialmente em SVG branco com fundo transparente.

Use nomes simples, em letras minúsculas e sem espaços, por exemplo: `empresa-exemplo.svg`.

Depois, edite `src/components/LogoCarousel.jsx` e altere um item para:

```js
{ name: 'Empresa Exemplo', src: '/logos/empresa-exemplo.svg' }
```
